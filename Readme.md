# Pokédex

Projeto desenvolvido durante o curso **JavaScript – API Pokémon**, com o objetivo de colocar em prática conceitos de desenvolvimento web e integração com APIs.

A aplicação consiste em uma **Pokédex interativa**, que permite visualizar informações sobre diferentes Pokémon utilizando dados fornecidos pela PokéAPI.

## Acesse o projeto

**[Visualizar Pokédex](https://SEU-PROJETO.vercel.app/)**

## Tecnologias utilizadas

- **HTML5:** estruturação da página.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** implementação da lógica, interatividade e manipulação do DOM.
- **PokéAPI:** fornecimento dos dados e imagens dos Pokémon.
- **Vercel:** hospedagem e publicação da aplicação.

## Funcionalidades

- Consulta de informações dos Pokémon por meio da PokéAPI.
- Exibição dinâmica de nomes e imagens.
- Navegação sequencial entre diferentes Pokémon.
- Visualização de Pokémon iniciais e de outras gerações.
- Atualização das informações na interface utilizando JavaScript.

## Aprendizados

Durante o desenvolvimento, foram trabalhados conceitos como:

- Consumo de APIs REST.
- Requisições HTTP com `fetch()`.
- Manipulação do DOM.
- Programação assíncrona com JavaScript.
- Integração entre HTML, CSS e JavaScript.
- Exibição dinâmica de dados externos.

## API utilizada

Os dados apresentados na aplicação são fornecidos pela **PokéAPI**, uma API pública que disponibiliza informações sobre o universo Pokémon.

Documentação oficial: https://pokeapi.co/
